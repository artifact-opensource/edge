# Security Policy

If you discover a security issue, follow this process:

1. Do NOT open an issue publicly for vulnerabilities.
2. Contact security@company.example (or the on-call security contact) with details and proof-of-concept.
3. Provide reproducible steps, affected components, and suggested mitigations.

We will acknowledge within 48 hours and follow responsible disclosure procedures.

## Security checks
- Secret scanning and SAST are enforced in CI.
- Rotations and revocations happen as needed by the security team.
