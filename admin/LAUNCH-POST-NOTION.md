## 🏗️ Technical Architecture

### Encryption: Shield256
- Algorithm: AES-256-GCM (authenticated encryption)
- Key derivation: scrypt (N=2¹⁷, r=8, p=1)
- Implementation: Python `cryptography` library
- Replaces: Legacy XOR-based system (removed)

### Database: SQLite + FTS5
- Engine: SQLite with FTS5 extension
- Documents indexed: 490
- Search: BM25 ranking, full-text search
- Tables: documents, projects, stakeholders, grc_controls, changelog
- API: `enterprise_db.py` — `EnterpriseDB` class with `search()`, `upsert()`, `get_by_id()`

### GRC Framework
- Controls: 52 total (mapped from SOC 2, ISO 27001, GDPR)
- Compliant: 19 (36.5%)
- In Progress: 23
- Not Started: 10
- Target: 80%+ by Q4 2026

- Security scanning (Bandit, CodeQL)

- Automated testing
