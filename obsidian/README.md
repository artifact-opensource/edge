## 📖 HOW TO USE THIS SYSTEM

### Daily Workflow

**Morning (Sunday Evening for Week Ahead):**
1. Open `ceo-weekly-sop.md` → Check today's departmental focus
2. Open `sop.md` → Review time block structure for the day
3. Open `todo.md` → Check today's critical tasks
4. Start executing with department-specific focus

**During the Day:**
1. Use `notes.md` for quick captures and decisions
2. Follow time blocks from `sop.md`
3. Stay focused on department of the day
4. Document important decisions in `notes.md` Decision Queue

**End of Day:**
1. Update `todo.md` with progress
2. Document any critical notes in `notes.md`
3. Review tomorrow's focus in `ceo-weekly-sop.md`
4. Prepare for next day's department

### Weekly Workflow

**Saturday Morning (Synthesis):**
1. Open `ceo-weekly-sop.md` → Saturday section
2. Complete Weekly Scorecard
3. Fill out Department Health Assessment
4. Answer Personal Leadership Reflection questions
5. Create Week Summary Document in `notes.md`

**Sunday Morning/Afternoon (Planning):**
1. Open `ceo-weekly-sop.md` → Sunday section
2. Select Next Week's Top 3 Priorities using ICE Framework
3. Plan Department Prep for each day
4. Process Decision Queue in `notes.md`
5. Update `todo.md` with next week's critical path

### Monthly Workflow

**Last Friday of Month:**
1. Review `objective.md` progress on KPIs
2. Update strategic initiatives status
3. Conduct monthly review of weekly operating system
4. Adjust department focus areas if needed

## 🎯 KEY PRINCIPLES

### 1. **One Department Per Day**
- Deep focus beats shallow scanning across all departments
- Reduces context switching and decision fatigue
- Creates predictable touchpoints for teams

### 2. **Weekend Synthesis & Planning**
- Saturday: Reflect, learn, consolidate the week
- Sunday: Plan, prioritize, prepare for next week
- Critical for avoiding overwhelm and maintaining clarity

### 3. **Dynamic Adaptation**
- Plans are guidelines, not rigid constraints
- Adjust when necessary, but return to rhythm
- Document changes and reasons

### 4. **Consolidated Documentation**
- Clear hierarchy prevents duplication
- Each document has specific purpose
- All documents reference each other

### 5. **Sustainable Pace**
- System designed to prevent burnout
- Weekend time includes personal renewal
- Energy management is strategic priority

## 🚨 TROUBLESHOOTING

### "I feel overwhelmed by too many things"
→ Read `ceo-weekly-sop.md` → Reducing Overwhelm section  
→ Focus on TODAY's department only  
→ Use Top 3 Priorities to filter noise

### "I don't know what to focus on today"
→ Open `ceo-weekly-sop.md`  
→ Check today's day of week  
→ That's your departmental focus  
→ Use that section's checklist

### "The plan isn't working this week"
→ Read Dynamic Adaptation Protocol in `ceo-weekly-sop.md`  
→ Adjust the plan, don't abandon it  
→ Document why in `notes.md`  
→ Return to rhythm next week

### "I haven't done Saturday synthesis in weeks"
→ Start with just 30 minutes this Saturday  
→ Focus on Week Summary only  
→ Build back to full synthesis gradually  
→ Schedule it in calendar as non-negotiable

### "Too many documents to track"
→ Remember the hierarchy: Weekly SOP → Daily SOP → Tasks/Notes  
→ Bookmark `ceo-weekly-sop.md` as your home base  
→ Use this README as quick reference
