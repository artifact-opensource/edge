## 1. Recruitment & Hiring

### 1.1 Job Requisition

**Requisition Process:**
1. Manager submits requisition
2. HR reviews requirements
3. Finance approves budget
4. VP/C-level approval (if required)
5. Job posting created

**Approval Matrix:**
| Level | Approver |
|-------|----------|
| Individual Contributor | Director + HR |
| Manager | VP + HR + Finance |
| Director+ | C-level + HR + Finance |

### 1.2 Sourcing & Screening

**Sourcing Channels:**
- Job boards (LinkedIn, Indeed)
- Employee referrals
- Recruiters (for senior roles)
- University partnerships
- Career fairs

**Screening Process:**
1. Resume review
2. Phone screen (HR)
3. Technical assessment
4. Interview rounds
5. Reference checks
6. Background check

### 1.3 Offer Management

**Offer Process:**
1. Determine compensation
2. Get approval (HR + Hiring Manager + Finance)
3. Prepare offer letter
4. Extend verbal offer
5. Send written offer
6. Negotiate if needed
7. Finalize acceptance

**Offer Contents:**
- Position and title
- Start date
- Compensation (salary, bonus)
- Benefits summary
- Reporting structure
- Contingencies

## 2. Onboarding

### 2.1 Pre-Boarding

**Before Start Date:**
- [ ] Send welcome email
- [ ] Prepare equipment (coordinate with IT)
- [ ] Set up workspace
- [ ] Create accounts
- [ ] Schedule orientation
- [ ] Assign buddy/mentor
- [ ] Prepare first week agenda

### 2.2 First Day

**Day 1 Checklist:**
- [ ] Welcome and introductions
- [ ] HR paperwork completion
- [ ] Benefits enrollment
- [ ] IT setup verification
- [ ] Security access
- [ ] Policy review
- [ ] Team lunch

### 2.3 First 90 Days

**Onboarding Timeline:**
| Period | Focus |
|--------|-------|
| Week 1 | Orientation, admin, meet team |
| Week 2-4 | Training, initial projects |
| Month 2 | Increased responsibilities |
| Month 3 | Full integration, 90-day review |

**90-Day Review:**
1. Manager feedback
2. New hire self-assessment
3. HR check-in
4. Identify any concerns
5. Confirm continued employment

## 3. Payroll & Benefits

### 3.1 Payroll Processing

**Payroll Schedule:**
- Pay frequency: Bi-weekly
- Pay day: Every other Friday
- Cutoff: Tuesday before pay day

**Payroll Process:**
1. Collect time and attendance
2. Process changes (new hires, terms, adjustments)
3. Run payroll calculations
4. Manager approval
5. Finance approval
6. Submit for processing
7. Distribute pay statements

### 3.2 Benefits Administration

**Benefits Enrollment:**
- New hires: Within 30 days of start
- Annual: Open enrollment period
- Life events: Within 30 days of event

**Benefits Offered:**
- Health insurance
- Dental/Vision
- Life insurance
- Retirement plan
- PTO
- Professional development

### 3.3 Leave Management

**Leave Types:**
| Type | Accrual/Allowance |
|------|-------------------|
| Annual Leave | 20 days/year |
| Sick Leave | 10 days/year |
| Personal | 3 days/year |
| Parental | 12 weeks |
| Bereavement | 3-5 days |

**Leave Request Process:**
1. Employee submits request
2. Manager approval
3. HR records in system
4. Calendar updated

## 4. Performance Management

### 4.1 Goal Setting

**Annual Goals:**
1. Manager and employee collaborate
2. Align with company objectives
3. Set 3-5 SMART goals
4. Document in system
5. Review quarterly

### 4.2 Performance Reviews

**Review Cycle:**
| Review | Timing |
|--------|--------|
| Quarterly check-in | Every 3 months |
| Mid-year review | June |
| Annual review | December |

**Review Process:**
1. Self-assessment
2. Manager assessment
3. Peer feedback (360)
4. Review meeting
5. Documentation
6. Development plan

### 4.3 Compensation Reviews

**Annual Compensation Process:**
1. Performance ratings finalized
2. Budget allocation
3. Manager recommendations
4. Calibration sessions
5. Final approvals
6. Communication to employees

## 5. Employee Relations

### 5.1 Issue Resolution

**Escalation Path:**
1. Direct conversation
2. Manager involvement
3. HR mediation
4. Formal investigation (if needed)
5. Resolution

### 5.2 Grievance Process

**Formal Grievance:**
1. Employee submits written grievance
2. HR acknowledges within 2 days
3. Investigation (if required)
4. Resolution meeting
5. Written response within 10 days
6. Appeal process (if needed)

### 5.3 Disciplinary Actions

**Progressive Discipline:**
| Step | Action | Documentation |
|------|--------|---------------|
| 1 | Verbal warning | Manager notes |
| 2 | Written warning | HR file |
| 3 | Final warning | HR file |
| 4 | Termination | Full documentation |

## 7. Offboarding

### 7.1 Voluntary Resignation

**Resignation Process:**
1. Employee submits resignation
2. Manager notification
3. HR exit interview scheduling
4. Knowledge transfer planning
5. System access coordination
6. Final pay calculation
7. Benefits continuation info

**Notice Period:**
- Individual contributors: 2 weeks
- Managers: 4 weeks
- Directors+: 6-8 weeks

### 7.2 Involuntary Termination

**Termination Process:**
1. Documentation review with HR
2. Legal review (if required)
3. Approval (HR + VP)
4. Termination meeting
5. Immediate access revocation
6. Final pay processing
7. COBRA/benefits info

### 7.3 Exit Process

**Exit Checklist:**
- [ ] Resignation/termination documented
- [ ] Exit interview completed
- [ ] Knowledge transfer done
- [ ] Equipment returned
- [ ] Access revoked
- [ ] Final pay processed
- [ ] Benefits terminated
- [ ] HRIS updated

## 8. Compliance

### 8.1 Record Keeping

**Retention Requirements:**
| Record Type | Retention |
|-------------|-----------|
| Personnel files | 7 years after term |
| Payroll records | 7 years |
| Benefits records | 6 years |
| I-9 forms | 3 years after term |
| Training records | 5 years |

### 8.2 Policy Management

**Policy Review Cycle:**
- Annual review of all policies
- Update as regulations change
- Employee acknowledgment
- Training on changes

### 8.3 Reporting

**Required Reports:**
- Headcount reports (monthly)
- Turnover analysis (quarterly)
- Diversity metrics (quarterly)
- Compensation analysis (annual)
- Regulatory reports (as required)
