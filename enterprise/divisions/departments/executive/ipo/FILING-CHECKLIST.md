# Pakistan IPO Filing Checklist

Quick reference checklist for filing patents and trademarks with IPO Pakistan.

---

## HEKTOR Patent Application Checklist

### Documents Required
- [x] Form P-1 (Application for patent) - **COMPLETED**
- [ ] Form P-3 (Provisional Specification) OR Form P-3A (Complete Specification)
- [x] Technical specification document - **COMPLETED**
- [ ] Certificate of Incorporation (photocopy)
- [ ] Board resolution authorizing patent filing
- [ ] Power of Attorney (if using agent)
- [ ] Pay Order/Bank Draft for filing fee (~PKR 10,000)
- [ ] Priority document (if claiming foreign priority) - N/A
- [ ] Drawings/diagrams (5 sheets) - to be prepared
- [ ] Claims (3 sheets) - to be prepared
- [ ] Abstract (1 sheet) - to be prepared

### Pre-Filing Steps
- [ ] Prior art search (Google Patents, patent databases)
- [ ] Ensure invention is not publicly disclosed
- [ ] Engage patent attorney for professional review
- [ ] Prepare detailed description (15 sheets)
- [ ] Draft patent claims (defining scope of protection)

### Filing Process
- [ ] Prepare all documents in duplicate
- [ ] Visit IPO Patent Office in Karachi OR send via registered post
- [ ] Submit documents and pay filing fee
- [ ] Receive receipt with application number
- [ ] Note filing date (important for priority)

### Post-Filing
- [ ] Monitor IPO website for examination reports
- [ ] Respond to office actions within deadline (usually 2 months)
- [ ] Check publication in Patent Journal (after 18 months)
- [ ] Monitor for oppositions (3 months after publication)
- [ ] Pay grant fees when patent approved
- [ ] Set reminders for annual fees (starting year 5)

**Estimated Timeline**: 18-24 months to grant  
**Estimated Cost**: PKR 175,000 (~$630 USD)

## Trademark Applications Checklist

### Priority 1: HEKTOR (HIGH PRIORITY)

#### Documents Required
- [ ] Form TM-1 (Application to register trademark)
- [ ] Certificate of Incorporation (photocopy)
- [ ] Company registration documents (SECP certificate)
- [ ] CNIC of authorized signatory
- [ ] Pay Order/Bank Draft (PKR 6,000 for 2 classes)
- [ ] Trademark in standard character form

#### Pre-Filing Steps
- [ ] Conduct trademark search at ipo.gov.pk/trademark-search
- [ ] Check for conflicts in Class 9 (software)
- [ ] Check for conflicts in Class 42 (SaaS)
- [ ] Verify distinctiveness (not generic/descriptive)

#### Goods/Services Description
- **Class 9**: Database software, vector database software, spectral analysis software, perceptual database software
- **Class 42**: Database as a service (DBaaS), software as a service (SaaS) featuring vector database, cloud database services

#### Filing
- [ ] Complete Form TM-1
- [ ] Submit to IPO Trademark Office, Karachi
- [ ] Pay filing fee (PKR 6,000)
- [ ] Receive filing receipt with application number
