## 1. Accounts Payable

### 1.1 Invoice Processing

**Invoice Receipt Process:**
1. Receive invoice (email/mail)
2. Log in AP system
3. Validate against PO (if applicable)
4. Route for approval
5. Record for payment

**Invoice Approval Matrix:**
| Amount | Approver |
|--------|----------|
| <$500 | Manager |
| $500-$5000 | Director |
| $5000-$25000 | VP |
| >$25000 | CFO |

### 1.2 Payment Processing

**Payment Schedule:**
- Domestic vendors: Net 30
- International vendors: Net 45
- Critical vendors: Per contract

**Payment Process:**
1. Verify approved invoices
2. Prepare payment batch
3. Get authorization
4. Execute payment
5. Record transaction
6. File documentation

### 1.3 Vendor Setup

**New Vendor Process:**
1. Receive vendor information
2. Verify tax documentation (W-9/W-8)
3. Validate banking details
4. Create vendor record
5. Verify with test payment
6. Activate vendor

## 2. Accounts Receivable

### 2.1 Invoice Generation

**Invoicing Process:**
1. Receive billable notification
2. Verify contract terms
3. Generate invoice
4. Review for accuracy
5. Send to customer
6. Record in AR

**Invoice Contents:**
- Invoice number and date
- Customer details
- Line item descriptions
- Amounts and taxes
- Payment terms
- Bank details

### 2.2 Collections

**Collection Timeline:**
| Days Past Due | Action |
|---------------|--------|
| 0 | Invoice sent |
| 7 | Reminder email |
| 30 | First collection call |
| 45 | Second notice |
| 60 | Escalation to manager |
| 90 | Legal review |

**Collection Process:**
1. Identify overdue invoices
2. Contact customer
3. Document communication
4. Escalate if needed
5. Negotiate payment plan (if appropriate)
6. Write off (with approval)

### 2.3 Payment Application

**Payment Reconciliation:**
1. Receive payment notification
2. Match to open invoices
3. Apply payment
4. Resolve discrepancies
5. Update AR records
6. Send receipt (if requested)

## 3. Expense Management

### 3.1 Expense Submission

**Expense Report Process:**
1. Employee submits report
2. Attach receipts
3. Manager approval
4. Finance review
5. Process reimbursement

**Expense Requirements:**
- Submit within 30 days
- Receipts required >$25
- Business purpose documented
- Appropriate category

### 3.2 Corporate Card

**Corporate Card Policy:**
- Business expenses only
- No personal use
- Receipts required
- Monthly reconciliation

**Card Reconciliation:**
1. Review monthly statement
2. Match to receipts
3. Categorize expenses
4. Submit for approval
5. Allocate to cost centers

### 3.3 Travel & Entertainment

**Pre-Travel Approval:**
| Trip Cost | Approver |
|-----------|----------|
| <$1000 | Manager |
| $1000-$5000 | Director |
| >$5000 | VP |

**Travel Booking:**
1. Get pre-approval
2. Book via approved channels
3. Select economy/standard options
4. Document business purpose

## 4. Budgeting & Forecasting

### 4.1 Annual Budget

**Budget Timeline:**
| Month | Activity |
|-------|----------|
| October | Guidance distributed |
| November | Department submissions |
| December | Consolidation and review |
| January | Board approval |

**Budget Process:**
1. Distribute templates
2. Gather departmental input
3. Consolidate submissions
4. Review with leadership
5. Iterate and finalize
6. Obtain approval
7. Distribute final budget

### 4.2 Monthly Forecasting

**Forecast Process:**
1. Gather actual results
2. Review with departments
3. Update projections
4. Analyze variances
5. Present to leadership

### 4.3 Variance Analysis

**Monthly Variance Review:**
1. Compare actual vs budget
2. Identify significant variances (>10%)
3. Investigate causes
4. Document explanations
5. Recommend actions

## 5. Financial Reporting

**Close Timeline:**

|-----|----------|

## 6. Treasury Management

### 6.1 Cash Management

**Daily Tasks:**
- Review bank balances
- Monitor cash position
- Process payments
- Review incoming payments

**Weekly Tasks:**
- Cash flow forecast (13 weeks)
- Investment review
- Debt monitoring

### 6.2 Banking Operations

**Bank Account Changes:**
1. Document requirement
2. Get CFO approval
3. Submit to bank
4. Verify changes
5. Update records

**Authorized Signers:**
- Maintain current list
- Review annually
- Update immediately on changes

### 6.3 Foreign Exchange

**FX Process:**
1. Identify FX exposure
2. Determine hedging need
3. Execute FX transaction
4. Record at correct rate
5. Monitor exposure
