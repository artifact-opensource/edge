## Brand Personality

### Voice & Tone

**Technical Precision**
- Clear, accurate, specific
- Evidence-based claims
- Technical depth without jargon overload
- Numbers and data over marketing speak

**Professional Confidence**
- Competent without arrogance
- Understated superiority
- Let results speak for themselves
- Humble expertise

**Innovation Focus**
- Forward-thinking
- Research-driven
- Cutting-edge but production-ready
- Practical innovation

### Communication Style

**Do:**
✓ Use clear, concise language  
✓ Lead with technical facts and data  
✓ Demonstrate expertise through content  
✓ Be specific and actionable  
✓ Use real-world examples  
✓ Acknowledge limitations honestly  

**Don't:**
❌ Use marketing hype or superlatives  
❌ Make unsubstantiated claims  
❌ Oversimplify complex topics  
❌ Talk down to technical audiences  
❌ Use buzzwords without explanation  
❌ Compromise technical accuracy for simplicity  

### Example Communication

**❌ Weak:**
"Artifact Virtual is revolutionizing the cloud industry with game-changing AI solutions!"

**✓ Strong:**
"Artifact Virtual delivers sub-3ms vector search with 98.1% recall@10 using perceptual quantization - a 3.5% improvement over standard approaches."

## Visual Identity

### Logo Usage

**Primary Logo**
- Used on: Website headers, official documents, presentations
- Minimum size: 120px width (digital), 30mm width (print)
- Clear space: Minimum 50% of logo height on all sides

**Secondary Logo**
- Simplified version for small applications
- Icons, favicons, social media profiles
- Minimum size: 32px × 32px

**Logo Variations**
- Full color (standard)
- White/light backgrounds (dark logo)
- Dark backgrounds (light logo)
- Monochrome (when color unavailable)

**Never:**
- Distort or rotate the logo
- Change logo colors
- Add effects (shadows, gradients)
- Place on busy backgrounds without proper contrast

### Typography

**Primary Typeface: Inter**
- Headings: Inter Bold (700)
- Body: Inter Regular (400)
- Emphasis: Inter Medium (500)
- Captions: Inter Light (300)

**Secondary Typeface: JetBrains Mono**
- Code snippets
- Technical documentation
- Monospaced data display
- Terminal/console displays

**Fallback System Fonts:**
- `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif`

**Type Scale:**

```
H1: 48px / 3rem (Desktop), 36px / 2.25rem (Mobile)
H2: 36px / 2.25rem (Desktop), 28px / 1.75rem (Mobile)
H3: 28px / 1.75rem (Desktop), 24px / 1.5rem (Mobile)
H4: 24px / 1.5rem (Desktop), 20px / 1.25rem (Mobile)
H5: 20px / 1.25rem (Desktop), 18px / 1.125rem (Mobile)
H6: 18px / 1.125rem (Desktop), 16px / 1rem (Mobile)

Body: 16px / 1rem
Small: 14px / 0.875rem
Caption: 12px / 0.75rem

Line Height: 1.6 (body text), 1.2 (headings)
```

### Iconography

**Style:**
- Line icons with 2px stroke weight
- Rounded corners (2px radius)
- 24×24px base size (scalable)
- Consistent visual weight
- Simple and recognizable

**Icon Library:**
- Material Design Icons (primary)
- Custom icons for specific features
- Maintain consistent style across all icons

**Usage:**
- Use sparingly and meaningfully
- Accompany with text labels when appropriate
- Ensure proper sizing and spacing
- Maintain contrast ratios for accessibility

## Imagery Guidelines

### Photography Style

**Preferred:**
- Authentic workspace photography
- Technology in action (data centers, servers, code)
- Team collaboration and expertise
- Modern, professional settings
- Good lighting and high quality

**Avoid:**
- Generic stock photos
- Staged or artificial scenarios
- Low quality or dated images
- Overly posed or formal
- Disconnected from technology context

### Illustration Style

**Approach:**
- Technical diagrams and schematics
- Architecture visualizations
- Data visualizations
- Isometric technical illustrations
- Clean, modern, technical aesthetic

**Characteristics:**
- Use brand color palette
- Maintain consistency across illustrations
- Balance detail with clarity
- Support technical understanding
- Professional and polished

## Digital Guidelines

### Website Design

**Principles:**
- Clean, modern, professional
- Content-first approach
- Fast loading and performant
- Mobile-responsive design
- Accessibility compliant (WCAG 2.1 AA)

**Components:**
- Consistent header/footer across site
- Clear navigation structure
- Prominent CTAs
- Whitespace for readability
- Technical credibility signals

### Social Media

**Profile Images:**
- Use primary logo
- Consistent across all platforms
- High resolution square format

**Cover Images:**
- Brand colors and typography
- Professional imagery
- Updated regularly for campaigns
- Consistent visual style

**Post Design:**
- Use brand templates
- Maintain color palette
- Include logo watermark
- Optimal dimensions per platform
- Professional and polished

### Email Design

**Layout:**
- Single column for mobile optimization
- Clear hierarchy
- Prominent CTA buttons
- Consistent header/footer
- Alt text for all images

**Branding:**
- Logo in header
- Brand colors for accents
- Professional typography
- Consistent with website design

## Compliance & Standards

### Legal Requirements

**Required Elements:**
- Copyright notices on all materials
- Trademark symbols on first use
- Legal disclaimers where appropriate
- Privacy policy links
- Terms of service references

**Copyright Notice:**
"© 2026 Artifact Virtual (SMC-Private) Limited. All rights reserved."

**Trademark Usage:**
First use: "Artifact Virtual™"  
Subsequent uses: "Artifact Virtual"

### Accessibility Standards

**WCAG 2.1 Level AA Compliance:**
- Color contrast ratios ≥4.5:1 (text)
- Color contrast ratios ≥3:1 (graphics)
- Alt text for all images
- Keyboard navigation support
- Screen reader compatibility
- Responsive text sizing

### Brand Protection

**Approved Uses:**
- Official company communications
- Authorized partner materials
- Press and media (with permission)
- Educational and reference uses

**Prohibited Uses:**
- Competitor materials
- Misleading associations
- Unauthorized commercial use
- Modified or altered logos
- Disparaging contexts
