## Document Standards

### Classification Levels

**Confidential (This Directory):**
- Executive and Board access only
- Contains sensitive financial information
- Competitive intelligence
- Strategic plans

**Internal:**
- Employee access (relevant roles)
- Operational documents
- General company information

**Public:**
- External stakeholder access

**All documents include:**
- Version number
- Last updated date
- Next review date
- Change log

**Update Process:**
1. Draft updates reviewed by relevant executives
2. CEO approval required for major changes
3. Board notification for strategic shifts
4. Version control maintained in git

**Ad-hoc:** Major market changes or strategic pivots
