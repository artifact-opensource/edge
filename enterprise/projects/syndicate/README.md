# Syndicate

> **Collaboration Platform** (Rebranded from GOLDMAX)

Enterprise collaboration platform for seamless team coordination, knowledge sharing, and project collaboration.

---

## 📋 Project Overview

**Syndicate** (formerly known as GOLDMAX for market analysis) is being evolved into a comprehensive collaboration platform that enables teams to work together effectively across projects, departments, and disciplines.

### Evolution Note

This project represents an evolution from the original GOLDMAX market analysis system into a broader collaboration platform. The core analytical capabilities remain, but are now part of a larger suite of collaboration tools.

---

## 🎯 Key Features

- **Team Workspaces** - Dedicated spaces for project teams
- **Real-time Collaboration** - Live document editing and communication
- **Knowledge Sharing** - Centralized knowledge base and wikis
- **Task Management** - Integrated project and task tracking
- **Integration Hub** - Connect with external tools and services
- **Analytics Dashboard** - Team productivity and project insights

---

## 🏗️ Architecture

### Platform Components

```
Frontend Layer (React/TypeScript)
    ├── Workspace UI
    ├── Real-time Collaboration
    └── Dashboard & Analytics
    ↓
API Gateway & WebSocket Server
    ↓
Microservices
    ├── User Service
    ├── Workspace Service
    ├── Document Service
    ├── Task Service
    └── Analytics Service
    ↓
Data Layer
    ├── PostgreSQL (primary data)
    ├── Redis (real-time state)
    └── S3 (file storage)
```
