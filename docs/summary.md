# Artifact Edge v3.1
> Reliable, low-cost distributed execution at the edge

- Problem: Edge apps lose work or double-execute tasks under flaky networks.
- Solution: Deterministic ownership + event sourcing + gossip = exactly-once execution and durable audit trail.
- Value: Lower infra cost, auditability, and resilience for edge deployments.
- Demo: `python scripts/demo.py` — shows ownership decisions, single execution, and persisted events.
- Ask: Approve a 6-week pilot on 5 edge sites (security hardening + monitoring).
