Component Specifications & Distributed Architecture
PYTHON 3.8+ / FLASK / RAW SOCKETS
EdgeNode Orchestrator
node/edge_node.py
Receives intents, creates canonical events, manages local SQLite WAL, calculates task ownership, and broadcasts to mesh peers.
Runtime Execution Loop
core/runtime.py
Threaded background agent loop executing registered task objects (e.g. MoveTask) exclusively when self-ownership is proven.
Consistent Hash Ring
core/ownership.py
Deterministic owner selection using SHA-256 hash modular mapping of task_id across peer nodes with zero central coordinator.
SQLite Persistent Store
storage/sqlite_store.py
Durable local event store with save_event() and idempotent has_event() checks to prevent replay execution loops.
Causal Vector Clock
core/vector_clock.py
Tracks logical time across distributed nodes, allowing deterministic conflict resolution and causal ordering during sync merges.
Gossip Protocol
mesh/gossip.py
Autonomous heartbeat thread syncing unseen canonical events over HTTP /sync endpoints across all registered peer nodes.
